# Sony ARW remaining-gap timings

Host: WSL2 Debian on AMD Ryzen 7 5800H, 15 visible CPUs. Kernel
6.6.87.1-microsoft-standard-WSL2, glibc 2.41, THP `[madvise]`, THP defrag
`[madvise]`. Release build, page-cache-hot inputs.

Method:

- Three fresh processes per case and thread count.
- Each process performed one warmup, then five rounds.
- Decoder order rotated each round, so Fornax, Rawler, and FlashRaw were
  interleaved within each process.
- Fifteen observations per decoder/case/thread count.
- Rawler used `decode_file`. Fornax timed
  `Decoder::decode(path).raw_mosaic()`. FlashRaw used CPU backend, strict
  corruption handling, `apply_opcodes=false`, `crop=false`, and 1 or 15
  workers.
- All values are milliseconds and are host-specific, not portable performance
  guarantees.
