# Panasonic RW2 references

This reference note records pinned sources, decoder behavior, and implementation boundaries for Panasonic RW2.

## Behavior References

### Rawler 0.8.0

- Crate: `rawler` 0.8.0.
- Upstream development source:
  `https://github.com/dnglab/dnglab`, commit
  `62b77de1a206d467e910d55199191068b45a9cc1`, particularly
  `rawler/src/decoders/rw2.rs` and its V4-V8 decompressor modules.

Rawler supplied behavioral evidence for the V4/V5/V6/V8 sample algorithms,
split block layout, packet layouts, V8 table interpretation, and strip

the documented bitstream behavior and fixture evidence. No Rawler source is
linked into production targets and no source is copied.

## Fixture-Pinned Tags

| File | Version `0x002d` | Compression `0x000b` | CFA `0x0009` | Active origin |
| --- | ---: | ---: | ---: | --- |
| DMC-G85 `_1030982.RW2` | 4 | 34316 | 4, BGGR | `(8, 8)` |
| DC-GH5S `P1022085.RW2` | 5 | 34316 | 1, RGGB | `(12, 8)` |
| DC-S1 `P1033119.RW2` | 6 | 34316 | 1, RGGB | `(12, 8)` |
| DC-GH6 `4-3.RW2` | 8 | absent | 1, RGGB | `(8, 8)` |

Crop tags `0x002f`-`0x0032` store exclusive top/left/bottom/right coordinates.
For example, the V4 fixture stores `8, 8, 3456, 4600`, which describes a
`4592x3448` crop rather than four margin sizes.
Older DMC-G7/G70 files store all four values as zero placeholders; those are
treated as the full active area.

White-balance tags in the four fixtures come from `0x0024`-`0x0026`. The
camera IFD is not required for basic decoding; malformed optional CameraIFDs
are ignored. Valid CameraIFDs are checked for the `0x1001` multi-shot fallback.

## Unsupported Evidence

- DC-G9 `P1000475.RW2` and DC-S5 `dc-s5_hr_96MP.RW2` carry nonzero multishot
  markers and are rejected before decoding.
- DC-S1R2 `S1Rii_multiexposure.RW2` has neither nonzero `0x0121` nor CameraIFD
  `0x1001`. Its V8 strip split `[4144, 4008]` differs from normal S1R2
  single-shot files `[4224, 3928]`, so that pinned split is rejected.
- 96-100 MP G9 II, GH6, S5 II, and S9 composite modes exceed the 64 MP
  single-shot layout bound and return typed unsupported errors.
- V7 remains unsupported because no real single-shot V7 fixture is available
  to validate a native codec.
