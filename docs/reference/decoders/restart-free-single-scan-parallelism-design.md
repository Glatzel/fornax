# Restart-free single-scan LJPEG parallelism design gate

Status: design complete, not approved for implementation. Recommendation: do
not implement until a boundary-discovery method avoids duplicating the hot
Huffman walk.

## Goal and scope

The target is a predictor-1 LJPEG scan with one large entropy segment and no
restart markers, such as Pentax K-5 `_MAR0543.DNG`. The post-#737/#738
measurement is about 93 ms at both 1T and 15T; tile-level Rayon work cannot
improve it. This design considers only internal entropy-difference decoding.
The owned-return API, error types, row ordering, and output representation stay
unchanged.

## Why predictor state can be separated

Huffman codes plus amplitude bits determine each difference without consulting
neighboring reconstructed samples. If exact symbol boundaries are known,
workers can decode differences into a temporary `i32` frame. Reconstruction can
then proceed deterministically:

1. Prefix-sum the first-column vertical predictor chain for each component.
2. Reconstruct rows in parallel, using the left-neighbor chain within each row
   and the already known above value for the first sample.
3. Write each row to its fixed output range.

This removes the serial predictor dependency, but it does not solve the harder
problem: finding exact symbol boundaries without restart markers.

## Boundary search considered

A JPEG codeword plus magnitude is at most 31 bits, so every 32-bit logical
entropy window contains at least one symbol boundary. Candidate positions could
therefore be generated by taking all 32 bit phases in a 4-byte window near a
target offset. A speculated worker would decode a signature of, for example,
256 difference tokens and record each token and consumed bit count.

Correct adjacent windows overlap exactly. A wrong bit phase will still decode
valid-looking Huffman symbols because the code is prefix-free, but matching a
256-token signature to the correct stream has negligible accidental-match
probability. A mismatch would discard the speculated segment and resume at the
last verified boundary. If no boundary can be verified through EOI, the whole
scan would fall back to the current sequential decoder.

The missing step is proving which candidate has the correct global symbol
ordinal. Windows spaced across a large scan do not inherently overlap. An
overlap chain must start at SOS and reach every candidate, or another trusted
pass must identify the exact bit position of each global symbol boundary.

## Boundary-discovery ruling

The only exact methods found so far are:

- sequentially walk the hot Huffman symbol/amplitude stream and record every
  bit position, then decode it again in parallel; or
- speculatively decode overlapping windows long enough to establish a verified
  chain from the first scan symbol to the last.

The first method duplicates most of the expensive entropy walk. The second
requires overlap or chain work large enough that the expected best case is near
break-even; malformed or highly repetitive data can force more speculation.
Neither establishes an obvious all-thread win from the measured baseline, so
this gate does not approve implementation.

## Exactness requirements for a future proposal

Any revised design must specify all of the following:

- how logical bit positions account for `FF 00` stuffing while preserving the
  terminating-marker boundary;
- how every candidate is assigned a unique global symbol index;
- why a wrong phase cannot be accepted from repeated signatures alone,
  including a quantified false-match bound;
- how workers compare both symbols and consumed bit lengths at overlaps;
- how a disagreement rolls back without publishing partial output;
- how the first-column predictor chain and row writes remain deterministic
  regardless of worker completion order;
- how truncated data, invalid Huffman codes, missing EOI, and unsupported
  precision retain current error semantics;
- how the implementation proves every symbol is decoded exactly once, with no
  skipped or duplicated rows;
- how the path chooses sequential fallback after charged speculation;
- the exact threshold and memory budget for the temporary difference frame.

## Required evidence before code

A proposal must first demonstrate boundary discovery alone on Pentax K-5 with
exact symbol count, bit positions, and token equality against the sequential
decoder. It must show that discovery plus parallel decode beats the current
1T and 15T wall time beyond noise and reports cycles/sample,
instructions/sample, and L1D load misses/sample. A design that merely moves the
same serial Huffman walk into a preparatory pass does not advance to code.

## Current decision

Keep the sequential restart-free decoder. Revisit parallelism only with a
restart-marker-bearing format, a container-supplied scan boundary, or a new
measured boundary-discovery primitive that does not duplicate the existing hot
walk.
