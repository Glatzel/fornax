# DNG remaining-gap profile shares

These are self-sample shares within each decoder, not contributions to the
Fornax/FlashRaw gap. Each graph was captured with
`perf record --call-graph dwarf,16384 -F 997` from the DWARF-enabled release
probe. The linked SVG and folded-stack files contain the full call trees.

## 5D3 LJPEG

Fornax:

- 38.29%: inlined row/sample sink closure.
- 28.57%: `HuffmanTable::decode_difference_fast`.
- 23.33%: `FastBitReader::fill_to`.
- 6.23%: `parse_jpeg`.
- 3.09%: fast row-decode closure.

FlashRaw:

- 91.76%: `decode_row_pred1::<BitPumpMsb>`.
- 3.15%: `unstuff_into`.
- 2.79%: `HuffTable::from_counts`.
- 0.82%: DNG compressed-U16 row closure.

## 5D3 uncompressed

- 1.86%: TIFF value destruction.

FlashRaw:

- 91.48%: `packed::unpack_row`.
- 4.58%: metadata `f32s` materialization.
