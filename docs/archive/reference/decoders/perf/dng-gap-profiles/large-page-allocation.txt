Linux large-page sample allocation
==================================

Host
----

WSL2 Debian, AMD Ryzen 7 5800H, 15 visible CPUs, kernel
6.6.87.1-microsoft-standard-WSL2, glibc 2.41, THP [madvise], THP defrag
[madvise]. Release build, page-cache-hot inputs, one warmup per process, five
measured rounds per process, three fresh processes per decoder. Baseline,
candidate, and FlashRaw processes were interleaved in one session by rotating
their order across processes.

Baseline: 985c704 (PR #736). Candidate: this branch. All rows passed exact
three-way dimensions, storage, bits, and pixel equality before timing.

5D3 uncompressed improves 61.1% at 1T and 61.6% at 15T. FP32 Deflate
improves 61.287 ms (15.3%) at 1T and 6.488 ms (9.7%) at 15T; both candidate
ranges are disjoint from baseline. FP16 improves 24.8% and 18.3%. No measured
case has a slower candidate median. The suggested 20% relative gate is not met
by FP32; the 1T absolute improvement matches the approximately 60 ms policy-era
expectation.

Linux huge pages and faults
---------------------------

Fresh process, one decode, no warmup. AnonHugePages is read from /proc/self/smaps
after the returned mosaic is complete. That inspection is excluded from the
wall-time table above.

Feature-off fallback
--------------------

The host cannot change /sys/kernel/mm/transparent_hugepage/enabled (non-root
and no_new_privs). The fallback proxy is the same candidate built with
large-page-hint disabled, measured with the same three-process, five-round,
same-session FlashRaw protocol.

The fallback changes no median by more than 2.5% except the noisy iPhone 15T
case; every range overlaps. It adds no material cost relative to the PR #736
baseline. A literal THP=never host run remains unperformed.

Decision
--------

Keep the module. The 5D3 uncompressed win is unambiguous, the FP32 1T absolute
win is approximately 61 ms, both thread-count ranges are separated, and no case
regresses beyond process noise. The relative FP32 result is below the suggested
20%, so this is an explicit judgment based on the restored policy's historical
ceiling, absolute gain, same-session FlashRaw ratio, and fault evidence.
