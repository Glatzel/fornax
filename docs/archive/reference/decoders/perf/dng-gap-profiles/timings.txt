# DNG remaining-gap timings

Method:

- Three fresh processes per case and decoder.
- Five interleaved rounds per process; each process performed one warmup first.
- `RAYON_NUM_THREADS=1`, release optimization, page-cache-hot inputs.
- Fifteen measurements per decoder and case. Values are milliseconds.

For later keep/revert decisions, a change is considered distinguishable only
when its before/after difference exceeds the larger observed process-level
spread rather than a single favorable run.
