# Encode Image Fast Path

## Goal

Simplify and accelerate `fornax_codec::encode_image` for uncompressed tile and
strip payload generation without changing the bytes it emits. Establish the
encoder as the standard synthetic fixture generator for codec roundtrip tests
and benchmarks.

## Scope

In scope:

- Characterization tests for every `SampleBuffer` variant, both byte orders,
  padded edge tiles, one-row, one-column, and single-tile geometry.
- Stable snapshots of the original encoder output.
- A generic typed encoder with one variant dispatch outside tile loops.
- Benchmark-driven rayon parallelism and a native-byte-order row copy.
- Measurement of per-chunk allocation cost.
- A shared seeded synthetic fixture utility used by tests and benchmarks.
- A short measured Encode section in the DNG performance report.

Out of scope:

- Decode implementation changes.
- Public API redesign for caller-owned output buffers.
- Changes to compressed encoders beyond reusing the improved uncompressed
  payload generator.
- Full workspace validation. The user explicitly requested that the previous
  validation run be skipped; this task runs focused tests and benchmarks.

## Validation

Run focused codec tests, the encode probe, synthetic fixture self-checks, and
format/diff checks. Benchmarks use release mode on the same host so before and
after values are comparable. Full `scripts/agent-validation.sh` is not part of
this task unless requested separately.

## Decisions and Notes

- The characterization snapshots are generated by the unmodified encoder
  before any production-code edit.
- Synthetic fixtures call the public uncompressed encoder, which delegates to
  `encode_image`; this avoids expanding the public API solely for test support.
- Real RAW inputs remain in Rawler and FlashRaw end-to-end comparisons.
- Changes are retained only when repeated measurements separate them from
  host noise.
- The original encoder's bytes were captured in 40 snapshots before the
  production refactor.
- The typed serial refactor reduced the large tile case from about 43.7 ms to
  41.5 ms.
- Indexed rayon was retained. A serial fallback is used below 1 MiB because
  dispatch overhead dominated small payloads.
- Native-order `bytemuck` row copies were reverted: large-case differences
  were within the observed spreads.
- A contiguous destination prototype was 4-7% faster end to end, but requires
  an `EncodedChunks` API redesign and was not retained.
